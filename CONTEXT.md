## Что это
Веб-сервис (React + TypeScript + Vite) для сборки мемориальных карточек
участников ВОВ по фиксированному дизайн-шаблону: редактор данных слева,
живой предпросмотр справа, экспорт готовой карточки в PNG/JPG/PDF.

## Репозиторий и деплой
- GitHub: **https://github.com/kfil-23/memory_book** (публичный, `gh` CLI
  авторизован под `kfil-23`)
- Живая версия: **https://kfil-23.github.io/memory_book/**
- Автодеплой через `.github/workflows/deploy.yml` — при каждом пуше в
  `master` GitHub Actions собирает `npm run build` и публикует `dist/` на
  Pages
- **Важно**: в `vite.config.ts` задан `base: '/memory_book/'`. Из-за этого
  все абсолютные пути к статике (`/icons/...`, `/st-george-ribbon.*`) в коде
  подставляются через `import.meta.env.BASE_URL`, а не хардкодятся — при
  добавлении новых public-ассетов это надо помнить. По той же причине
  **dev-сервер открывается на `http://localhost:5173/memory_book/`, а не на
  корне**.

## Ключевые решения и грабли (важно не наступить повторно)
1. **`backdrop-filter` несовместим с `html-to-image` (экспорт в PNG)** — рвёт
   скруглённые углы, даёт «протекающий» блюр-ореол. Решение: свой блюр-слой
   — клон фона `filter: blur()`, обрезанный через `overflow:hidden` на
   родителе (не `backdrop-filter`).
2. **`mix-blend-mode` (слой зерна) «протекает» за `border-radius`/
   `overflow:hidden` родителя** — известный баг рендеринга. Фикс:
   `isolation: isolate` на родительском `.panel`.
3. **SVG как `<img>` с `object-fit: fill`** без атрибута
   `preserveAspectRatio="none"` в самом SVG растягивается не полностью в
   некоторых движках — оставляет непрокрашенную полосу у края. Всегда
   добавлять `preserveAspectRatio="none"` в корневой `<svg>`, если он
   используется как растягиваемая подложка.
4. **Две копии одного фона (основной слой + блюр-клон под панелью) должны
   иметь идентичную геометрию рамки** (тот же `inset`/масштаб/центр), иначе
   `background-size: cover` даёт разный кроп и на границе панели виден
   «скачок» картинки.
5. **Веб-шрифт может не быть загружен на момент первого измерения**
   (подгонка ФИО/плотности текста) — оба хука перезапускают измерение после
   `document.fonts.ready`.
6. Хардкод абсолютных путей (`src="/icons/..."`) ломается под непустым
   `base` — использовать `import.meta.env.BASE_URL`.

## Текущее состояние карточки (дизайн)
- Холст 1672×895px, экспорт 3344×1790 (2×)
- Панель текста: CSS-подложка (не SVG-картинка) — градиент прозрачности
  слева→направо `rgba(250,246,235, 0.54→0.28)`, лёгкое зерно (`opacity
  0.25`, mix-blend-mode overlay, `isolation:isolate` для чистых краёв),
  блюр-клон фона позади
- Иконки разделов — SVG (line-style, 44px), выровнены в одну строку с
  заголовком
- Портрет отцентрирован по вертикали с текстовой панелью
- Лента — фиксированное изображение (`st-george-ribbon.webp`) в правом
  нижнем углу карточки, `right:0; bottom:0`
